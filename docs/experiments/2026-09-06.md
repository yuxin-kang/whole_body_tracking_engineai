## Controlled difference

| Arm | Task | Change from original j9519 |
| --- | --- | --- |
| A (`ori`) | `Tracking-Flat-T800-GetUp-Recovery-Ori-v0` | Add reference anchor orientation reward, weight 0.5, std 0.4, smoothstep ramp at phase 0.40–0.45, then hold |
| B (`ori_velgate`) | `Tracking-Flat-T800-GetUp-Recovery-OriVelGate-v0` | Same as A, plus pose-dependent late linear/angular body-velocity reward gate |

Both keep the original all-episode position/orientation weights 0.5/0.5,
height weight 1.25 at phase 0.20–0.90, transition joint weight 1.5, all other
rewards and physical/observation/action contracts. The extra orientation term
raises effective orientation weight from 0.5 to 1.0 at about 3.02–3.40 seconds.
There is no additional 90%-phase bonus from the later failed experiments.

B's gate ramps in at phase 0.70–0.80 (about 5.29–6.05 seconds):

```text
confidence = exp(-(z_ref-z)^2 / 0.25^2 - quat_angle_error^2 / 0.60^2)
factor = 1 - smoothstep(phase; 0.70, 0.80) * (1 - (0.10 + 0.90 * confidence))
velocity_reward_B = original_velocity_reward * factor
```

The gate compares the reference pose, not absolute upright posture. It leaves
early velocity rewards unchanged and retains a 10% floor late in a failed pose.
The velocity term weights/stds themselves remain 1.0/1.0 and 1.0/3.14.

## Execution and validation

Launcher: `scripts/slurm/finetune_t800_getup_2x4090.sbatch`.
The partition allocates 2×`rtx4090d` together; two exclusive Slurm steps each
receive one GPU. A/B are independent PPO processes, not a distributed model.

Before long training, BOTH arms must pass a 32-environment, 10-update preflight
(480 control steps, covering the complete motion). Each checks input hashes,
reward-only changes, registered Play config equivalence, exact checkpoint and
optimizer restoration, actor/critic observation widths 134/284, finite updated
parameters, effective LR, and a saved final checkpoint. The launcher requires
a `completed` manifest rather than trusting Kit's shutdown exit code alone.

Every run writes `finetune_manifest.json` and `params/{env,agent}.{yaml,pkl}`.
W&B receives scalar curves/configuration; model files remain local.

## Evaluation criteria

Compare against original j9519 using the same trajectory and startup setup:
orientation and horizontal error at 3–5.5 seconds, knee extension timing, base
height and tilt, and sustained final two-foot upright behavior. Check early
get-up ability for regression. Do not rank changed reward totals as a success
metric. Independent seeds and visual Play are still needed to judge robustness.
